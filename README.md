VELVET Connect

VELVET Connect is an exclusive yet affordable social dating platform designed to help users build meaningful connections through a polished, safe, and modern mobile experience.

Project Status

VELVET Connect is currently in the MVP planning and foundation stage. The immediate focus is establishing the product requirements, SwiftUI application structure, Supabase backend, moderation tools, subscription model, and investor-ready demo materials.

MVP Goal

The first release should allow a user to:

1. Create an account.
2. Complete a profile and upload photos.
3. Set discovery preferences.
4. Browse profiles.
5. Like or pass on profiles.
6. Create a mutual match.
7. Exchange messages.
8. Block or report another user.
9. Access selected VIP features through a subscription.

Backend

The planned backend is Supabase and will support:

* Authentication
* User profiles
* Photo storage
* Preferences
* Likes and matches
* Messaging
* Reports and blocks
* Subscription entitlements
* Row-level security
* Basic analytics and event tracking

Admin Dashboard

* Secure administrator access
* User search and account review
* Photo verification review
* Report and moderation queue
* Suspend and reactivate accounts
* Basic platform analytics

Subscriptions

The MVP will begin with one VIP membership tier. Planned capabilities include:

* Apple in-app purchase support
* Purchase and restore flows
* Subscription entitlement tracking
* VIP feature access
* Renewal and cancellation handling

Definition of Done

A task is complete when:

* The implementation or document exists in the repository.
* Acceptance criteria have been met.
